# Create Project Command

## Command: `create-project`

Generates a new Unreal Engine C++ project structure.

### What It Does

1. Creates the project directory structure
2. Generates base C++ classes
3. Sets up CMake build configuration
4. Creates default configuration files
5. Initializes Git tracking

### Usage

```
skills/unreal-game-dev/commands/create-project.md
```

### Output

- `Source/` directory with project structure
- `CMakeLists.txt` for building
- Base Actor, GameMode, and AI Controller classes
- Project configuration files

### Notes

Run after `setup-env` to create your project template.

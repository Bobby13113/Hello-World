# Setup Environment Command

## Command: `setup-env`

Initializes the development environment with proper structure and configuration.

### What It Does

1. Creates necessary project directories
2. Sets up Git configuration
3. Configures VS Code settings
4. Creates build configuration files
5. Initializes documentation structure

### Usage

```
skills/unreal-game-dev/commands/setup-env.md
```

### Output

After running, you'll have:

- Complete Unreal Engine project structure
- Git repository initialized
- VS Code workspace configured
- CMake build system ready
- Documentation templates

### Notes

Run this command before starting any development work.

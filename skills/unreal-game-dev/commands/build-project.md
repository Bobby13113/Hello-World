# Build Project Command

## Command: `build-project`

Builds the Unreal Engine project for Windows PC.

### What It Does

1. Compiles C++ source files
2. Generates build artifacts
3. Creates executable for Windows platform
4. Runs build verification checks

### Usage

```
skills/unreal-game-dev/commands/build-project.md
```

### Output

- Compiled binaries in `Binaries/Win64/`
- Build logs in `Saved/Logs/`
- Executable ready for testing

### Notes

- Run after making code changes
- Test build on target platform regularly
- Check logs for compilation warnings/errors

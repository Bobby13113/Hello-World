# Cline Workspace Configuration

## Workspace Overview

This workspace is configured for developing **"AI Overlords, Resistance is Futile"** - a PC game built with Unreal Engine.

## Workspace Skills

### Unreal Engine Game Development

Location: `skills/unreal-game-dev/`

This skill provides:

- C++ code generation for Unreal Engine classes
- AI Overlords-themed templates
- Build and deployment commands
- Git workflow support
